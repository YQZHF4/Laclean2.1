# Laclean Studio

面向激光清洗平台的机械臂离线编程桌面软件。目前已建立第一阶段工程骨架：

- PyQt5 深色工业风主界面
- 项目对象树和节点右键菜单
- OCC 中央三维窗口
- 属性面板、状态栏和功能预留入口
- 相机、机械臂、振镜、路径规划等服务接口
- 新建、打开、保存和另存为项目
- 版本化 `project.lcp`、原子保存和可迁移资产目录
- PCD/PLY/XYZ/XYZN/XYZRGB/PTS 点云导入
- STEP 数模和机械臂模型导入、OCC 着色显示及项目恢复
- 点云源文件自动复制到项目、OCC 显示与项目重载恢复
- 点数、颜色、法线、包围盒、单位和资产路径属性
- 点云三轴平移箭头与三轴旋转圆环操纵器（禁用缩放）
- 操纵器局部/世界坐标切换及 4×4 位姿持久化
- 基础点云处理流水线及非破坏性三维预览
- 体素降采样、统计滤波、半径滤波和法线估计
- 屏幕矩形穿透框选、保留框内或删除框内
- 点云裁剪撤销/重做（`Ctrl+Z` / `Ctrl+Y`）

## 源码结构

当前仓库根目录是源码工程，不是软件保存出来的业务项目目录：

```text
Laclean2/
├─ 图片/
├─ 资料/
├─ projects/
├─ scripts/
├─ src/
│  └─ laclean/
├─ tests/
├─ main.py
├─ pyproject.toml
└─ README.md
```

- `src/laclean/`：应用源码。
- `tests/`：自动化测试。
- `scripts/`：冒烟测试、性能基准和辅助脚本。
- `projects/`：示例或本地保存的业务项目。
- `资料/`、`图片/`：示例模型、说明资料和图片资源。
- `main.py`：本地开发启动入口。
- `pyproject.toml`：项目元数据、依赖声明、打包入口和 pytest 配置。

## 软件项目结构

软件新建或保存的业务项目使用下面的结构，仓库内的 `projects/111/` 是一个示例：

```text
项目名称/
├─ project.lcp
├─ assets/
│  ├─ pointclouds/
│  ├─ cad/
│  └─ robots/
├─ cache/
└─ autosave/
```

`project.lcp` 使用 UTF-8 JSON，保存场景树、节点 UUID、可见状态和停靠面板布局。
项目资产统一使用相对路径，整个项目文件夹可以直接迁移。

导入点云时必须先保存项目。源文件会复制到
`assets/pointclouds/<节点UUID>/`；软件显示的是项目内副本，原始外部文件移动或删除后仍可重新打开项目。

## STEP 数模与机械臂

- 工具栏或文件菜单的“导入数模”会把 `.step/.stp` 加入“数模”组。
- 文件菜单的“导入机械臂 STEP”，或右键“机械臂”对象组使用同名命令，会把 STEP
  加入机械臂组并移除“机械臂接口（预留）”占位节点。
- STEP 在后台使用 OCCT 读取、统计实体与面数并完成并行三角化；AIS 着色显示发生在
  UI 线程。模型可通过对象树复选框显示或隐藏。
- 数模复制到 `assets/cad/<节点UUID>/`，机械臂复制到
  `assets/robots/<节点UUID>/`，项目移动后仍能恢复。
- 机械臂模型节点继续提供正运动学、逆运动学和碰撞检测预留菜单。

仓库内的 `资料/【机械臂R6-093S】客户模型.stp` 已通过实际验证：9.3 MB、1 个 STEP
根、55 个实体、4,426 个面，解析和三角化约 3.7 秒，OCC 首次显示约 0.2 秒。
可独立复测导入、显示、保存和项目重开恢复：

```powershell
$env:PYTHONPATH = (Resolve-Path src).Path
python scripts\smoke_test_step.py "资料\【机械臂R6-093S】客户模型.stp"
```

## 点云操纵器

在对象树中选中可见点云，操纵器会自动显示在点云包围盒中心：

- 拖动红、绿、蓝箭头，分别沿 X、Y、Z 平移。
- 拖动红、绿、蓝圆环，分别绕 X、Y、Z 旋转。
- 中央视图顶部可隐藏/显示操纵器，并切换“局部”或“世界”坐标。
- 右侧属性面板实时显示位置 XYZ 和旋转 Rx/Ry/Rz。
- 操纵器不提供缩放，避免改变点云的物理尺寸。

拖动完成后项目标题会出现 `*`。按 `Ctrl+S` 保存，重新打开项目后位姿会恢复。

## 点云处理与预览

右键点云节点，选择“基本点云处理”。可按固定顺序组合启用：

1. 体素降采样
2. 统计离群点滤波
3. 半径离群点滤波
4. 法线估计

点击“预览”后，计算在后台线程执行，中央三维窗口临时显示处理结果，并给出每一步
的输入/输出点数和耗时。修改参数、点击“取消预览”或关闭窗口会恢复当前已应用点云。
只有点击“应用结果”才会在节点资产目录写入新的 `processed_*.ply`，并更新节点的
点数、包围盒、颜色、法线和处理历史。最初导入的文件由 `original_asset` 记录并保留，
不会被覆盖。应用后仍需按 `Ctrl+S` 保存项目元数据。

## 矩形裁剪与撤销

右键可见点云节点，选择“手动矩形裁剪”：

1. 中央视图进入“矩形框选 · 穿透”模式，按住左键拖出矩形。
2. 框选使用完整点云和当前点云位姿进行屏幕投影，不受 OCC 显示代理限制，也不做
   深度遮挡判断，因此矩形视锥中的前后层点都会被选中。
3. 框选结束后选择“保留框内”或“删除框内”，也可以取消。
4. 右键或 `Esc` 可退出框选模式。

裁剪结果保存为节点目录下新的 `cropped_*.ply`，之前的资产不会被覆盖。使用
`Ctrl+Z` 撤销最近的点云裁剪，使用 `Ctrl+Y` 重做；编辑菜单会显示即将撤销或重做的
操作名称。当前会话最多保留 20 步裁剪命令，打开其他项目时命令历史清空。裁剪或
撤销/重做后仍需按 `Ctrl+S` 保存当前项目状态。

## 大点云性能与异常处理

- OCC 显示代理默认最多 18 万点；完整点云达到 300 万和 1,000 万点时自动降低到
  14 万和 10 万点。只降低显示密度，不改变算法、框选和保存使用的完整数据。
- 可通过环境变量 `LACLEAN_DISPLAY_POINT_LIMIT` 调整基础显示预算，允许范围为
  1 万至 100 万点。
- 显示代理使用零拷贝步进视图。矩形框选以 25 万点为一块执行 `float32` 投影，避免
  为完整点云同时生成多份齐次坐标和 NDC 数组。
- `processed_*.ply` 和 `cropped_*.ply` 使用分块二进制 PLY 流式写入，避免写盘前
  创建完整的 Open3D `float64` 副本。
- 大文件复制和结果写入前会检查磁盘剩余空间，并预留 64 MB 安全余量。
- 撤销历史最多 20 步，同时具有 768 MB 内存预算；超过预算时优先释放较早的命令，
  始终尽量保留最新一次裁剪以供撤销。
- 损坏 JSON、重复 UUID、危险资产路径、无效点云元数据和超过 64 MB 的异常项目文件
  会在加载阶段被拒绝。
- 内存不足、磁盘空间不足、权限错误和后台线程异常会显示可操作的中文提示。完整异常
  堆栈写入 `%LOCALAPPDATA%\Laclean Studio\logs\laclean.log`，日志单文件 2 MB，
  最多保留 3 份历史。

可运行重复性性能基准：

```powershell
$env:PYTHONPATH = (Resolve-Path src).Path
python scripts\benchmark_large_point_cloud.py --points 5000000 --write
```

当前开发机的 500 万点基准：完整数据约 60 MB，矩形框选约 0.13 秒，60 MB 二进制
PLY 流式写入约 0.09 秒；真实 OCC 上传 138,889 个显示点约 1.26 秒。结果受 CPU、
磁盘和显卡驱动影响，仅作为版本间回归参考。

真实 OCC 冒烟测试会自动创建点云、上传显示、核对相机投影并模拟鼠标拖框，然后关闭：

```powershell
$env:PYTHONPATH = (Resolve-Path src).Path
python scripts\smoke_test_occ.py --points 1000000
```

## 依赖

推荐使用 Windows + Conda 环境运行。Python 版本要求：

```text
>=3.11,<3.12
```

运行依赖：

- `PyQt5>=5.15,<6`
- `numpy>=2.2,<3`
- `open3d>=0.19,<0.20`
- `pythonocc-core=7.9.3=novtk*`

测试依赖：

- `pytest`

OCC 推荐使用 conda-forge 的无 VTK 构建，避免与环境内现有的 Open3D/VTK 冲突：

```powershell
conda install -c conda-forge "pythonocc-core=7.9.3=novtk*" "numpy=2.2.6" "pyqt=5.15.*"
python -m pip install "open3d>=0.19,<0.20"
python -m pip install -e . --no-deps --no-build-isolation
```

如果需要运行测试：

```powershell
conda install -c conda-forge pytest
```

## 运行

在项目根目录执行：

```powershell
python main.py
```

如果已经以可编辑模式安装项目，也可以使用命令入口启动：

```powershell
laclean
```

## 测试

```powershell
$env:PYTEST_DISABLE_PLUGIN_AUTOLOAD = "1"
python -m pytest
```

当前自动化测试覆盖项目损坏检测、点云导入异常、算法处理、百万点分块框选、流式 PLY、
裁剪保留/删除、撤销/重做、保存重开和界面集成。测试会禁用 OCC 原生窗口并使用 Qt
的 offscreen 平台。关闭 pytest 外部插件自动加载可以避免用户目录中与本项目无关的
插件影响测试结果。原生 OCC 鼠标拖框、相机投影和大点云上传另使用真实窗口冒烟验证。
